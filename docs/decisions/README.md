# Decisiones de Orlando

La presentación editable y su PDF se generan al finalizar la implementación en
`documents/`. Las decisiones no resueltas se conservan como preguntas de
validación, no como configuraciones asumidas:

1. dominio y titularidad;
2. cuentas de GitHub, Google y Cloudflare;
3. texto de consentimiento y WhatsApp oficial;
4. acceso de cada gestor;
5. criterio de aprobación y SLA;
6. límite que justificaría un plan de pago;
7. canales que se activan primero;
8. casos y materiales que pueden mostrarse de forma anónima.
